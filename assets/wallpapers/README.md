# 壁纸放这里

程序启动时会扫描本目录，把找到的图片自动列进「**设置 → 外观**」，默认使用其中的第一张。

支持格式：`.jpg` / `.jpeg` / `.png` / `.webp` / `.bmp`

## 为什么仓库里是空的？

本仓库**不附带壁纸**。开发时使用的几张初音未来插画来自 pixiv，版权归各画师所有，
不适合在公开仓库里再分发，所以没有一起提交。

程序在找不到任何壁纸时会自动使用**初音配色的深蓝渐变背景**，功能完全不受影响 ——
只是少了人物插画。

## 怎么换成自己喜欢的图

1. 把你喜欢的图片复制到本目录（`assets/wallpapers/`）；
2. 重新启动程序，或者进「设置 → 外观」点一下即可切换；
3. 文件名随意，想显示成中文名的话可以改 `cts/resources.py` 里的 `order` 列表。

壁纸会自动铺满整个窗口：程序用 `KeepAspectRatioByExpanding` + 居中裁剪绘制，
任何窗口比例下都不会出现空白。

> 如果你要自己重新打包 exe，记得在打包前把图片放进来 —— `ComfyUI_TagSelect.spec`
> 会把整个 `assets/` 目录一起打进去。
